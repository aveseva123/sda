# Цех HoReCa в Ереване — бизнес-план

Внутренний одностраничный сайт для переговоров с инвестором: 13 разделов с якорной навигацией, интерактивная финансовая модель, экспорт в PDF. Без бэкенда и авторизации.

## Запуск

```bash
cd intranet
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/, ее можно положить на любой статический хостинг
npm run preview    # посмотреть собранную версию
npm test           # тесты финансовой модели (vitest)
```

Node 22 или новее.

## Где менять данные

Все тексты и цифры лежат в `src/data/`, каждый файл — плоский массив или объект с комментариями:

| Файл | Что внутри |
|---|---|
| `summary.ts` | Тексты резюме, три формата сделки |
| `founder.ts` | Раздел «Кто я»: плитки, клиенты, материалы |
| `market.ts` | Игроки рынка, ниша, блок «к уточнению» |
| `product.ts` | Что делаем на старте и позже, ценовые ориентиры |
| `premises.ts` | Требования к помещению, районы, кандидаты по умолчанию, план поиска |
| `equipment.ts` | Станки: цена от–до, откуда, состояние |
| `logistics.ts` | Маршруты доставки оборудования |
| `team.ts` | Штат на старте: роль, количество, зарплата gross |
| `operations.ts` | Цепочка процесса и практики |
| `finance.ts` | Параметры финмодели: значения по умолчанию, диапазоны ползунков, константы |
| `investor.ts` | Три варианта условий для инвестора |
| `roadmap.ts` | Полосы и вехи дорожной карты |
| `risks.ts` | Таблица рисков |
| `nextSteps.ts` | Списки «до второй встречи» |
| `sections.ts` | Порядок и названия разделов в навигации |

Итоги таблиц, ключевые цифры резюме и графики считаются из этих данных автоматически — руками их править не нужно.

## Что можно менять прямо на сайте

- **Оборудование**: включать и выключать строки, менять количество и цены от–до, добавлять свои станки.
- **Команда**: включать и выключать роли, менять количество и зарплату, добавлять свои роли.
- **Константы модели**: доставка, подготовка, налоги, электричество, материалы, разгон заказов, сценарии загрузки.
- **Общежитие и питание**: плитка в разделе «Команда» с четырьмя параметрами (проживание, питание, доля штата, скидка к зарплате). По умолчанию нули, кнопка «Подставить пример» показывает механику; значения — те же константы модели.
- **Ползунки** финансовой модели.

Все правки живут в адресе страницы вместе с ползунками, поэтому «Скопировать ссылку» отдает полный сценарий. Кнопки «Вернуть исходный список», «Вернуть исходный штат», «Вернуть по умолчанию» откатывают свою часть, «Сбросить все» — все сразу. Выключенные строки в расчет не идут.

План описывает один стартовый набор станков и стартовый штат: фаз расширения и второго сценария нет. Металл (каркасы, нержавейка) — субподряд, своего металл-поста и сварщика в плане нет.

Ключи в адресе: `eq` — правки станков, `eqx` — добавленные станки, `tm` — правки штата, `tmx` — добавленные роли, `c` — константы. Формат описан в `src/model/config.ts`, там же тесты на разбор.

## Финансовая модель

Чистые функции в `src/model/finance.ts`, тесты рядом в `finance.test.ts`. Ползунки раздела «Финансовая модель» меняют параметры из `src/data/finance.ts` (`financeDefaults`); значения констант по умолчанию и их подписи для панели на сайте — в `financeConstants` и `constantGroups` там же.

Состояние ползунков хранится в query-параметрах адреса, например:

```
/?area=500&rent=6&budget=40000&anchor=4&ext=8&margin=38&m0=3&res=15&amd=390
```

Кнопка «Скопировать ссылку» копирует адрес с текущим сценарием. localStorage не используется.

## Экспорт в PDF

Кнопка «Экспорт в PDF» вызывает системную печать. В печати: светлый фон, без навигации и ползунков, каждый раздел с новой страницы. Для лучшего результата в диалоге печати включите «Фоновая графика».

## Структура

```
src/
  data/         данные разделов
  model/        финансовая модель и тесты
  sections/     по компоненту на раздел
  components/   навигация, плитки, ползунок, график
  hooks/        параметры в URL, активный раздел
  lib/          форматирование чисел
  index.css     токены, аврора, стекло, печать
```
