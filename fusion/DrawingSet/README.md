# DrawingSet — комплект чертежей мебельного изделия из Fusion

Add-in для Autodesk Fusion (Python). По активной 3D-модели, собранной из панелей,
**сам рисует** комплект чертежей и показывает его в палитре Fusion (встроенный webview),
затем пишет PDF, DXF, SVG и CSV. Fusion Drawing API не используется: в майском релизе 2026
он публично умеет только экспортировать PDF, а автосоздание чертежей там скрыто и не
поддерживается (подробности ниже). Путь «через Fusion Drawing» оставлен как запасной
режим по флажку.

| Модуль | Что делает |
|---|---|
| **А. СБ** — сборочный чертёж | главный вид, сверху, слева (ISO — первый угол; ASME — третий), изометрия с позиционными выносками, габаритные размеры, спецификация; по флажку — листы на подсборки |
| **Б. ВЗР** — взрыв-схема | разнесённая изометрия с той же нумерацией, таблица фурнитуры; по флажку — схема на каждую подсборку; крепёж скрыт / едет с деталью / показан |
| **В. ДЕТ** — деталировка | лист на каждую уникальную панель (одинаковые объединены с количеством): вид на пласть, два вида на кромки, отверстия с обеих сторон и в торцах (скрытые — пунктиром), размеры отверстий цепочкой или от базы, список отверстий «n×⌀d гл. h», кромка в шапке; листовой металл — развёртка с линиями гиба и таблицей гибов |
| **Г. Экспорт** | PDF (шрифт DejaVu Sans встроен, кириллица), DXF R12 листов, DXF контуров деталей 1:1 для раскроя (слои CONTOUR / HOLES / HOLES_BACK), SVG, CSV; имя файла по маске `{проект}_{вид}_{изделие}_{тип}`; по флажку один сводный PDF |

Add-in встраивается после ваших скриптов переименования/нумерации: он **читает** имена вида
`37-4_В1_П03_Боковина` и присвоенные позиции, ничего не переименовывает и своих номеров
не придумывает. Номера в выносках = позиции из имён, всегда.

## Как это работает

1. **Модель** (`lib/model.py`): обход вхождений, разбор имён, материал, толщина и размер по
   ориентированному боксу, категории (боковина/полка/фасад/задняя стенка/крепёж), кромка,
   листовой металл, маркеры разрезов. По флажку записывает позицию в `partNumber` и
   сводку в `description` компонента.
2. **Геометрия** (`lib/extract.py`): грани как многоугольники (контуры с отверстиями),
   кривые кромки штрихуются с точностью 0,2 мм, отверстия распознаются по цилиндрическим
   граням (вход, ось, диаметр, глубина, сквозное). Развёртка — из `FlatPattern.flatBody`.
3. **Разнесение** (`lib/explode.py`): нормаль панели — ось наименьшего габарита; сдвиг от
   центра изделия на `max(коэффициент × толщина, шаг)`; фасады и задняя стенка сильнее,
   полки вперёд; «перёд» по задней стенке, иначе по фасаду, иначе из настроек; центральная
   перегородка на месте; параллельные панели ступенчато; подсборки целиком, по флажку с
   внутренним разнесением. Копии дизайна больше не нужны: смещения применяются только при
   проекции.
4. **Рендер** (`lib/render/`): ортогональные и изометрические проекции, алгоритм художника
   (грани закрашиваются от дальних к ближним, поэтому невидимые линии перекрываются),
   размеры, выноски, таблицы, рамка и штамп. Один набор примитивов пишется в SVG (для
   палитры), PDF (свой писатель с внедрённым TrueType) и DXF R12 (кодовая страница 1251).
5. **Палитра** (`resources/palette/`): форма настроек (та же схема, что и у нативного
   диалога), кнопки «Сгенерировать» / «Экспорт» / «Открыть папку», список листов,
   просмотр с масштабированием и панорамированием, журнал с предупреждениями.

Ограничение алгоритма художника: пересекающиеся тела и криволинейные поверхности
(трубы) рисуются приближённо — только рёбра, без точной линии силуэта. Для корпусной
мебели из панелей это не проявляется.

## Установка и запуск

1. Скопируйте папку `fusion/DrawingSet` в каталог add-in'ов:
   Windows `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\DrawingSet`,
   macOS `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/DrawingSet`.
   Внутри должны лежать `DrawingSet.py`, `DrawingSet.manifest`, `lib/`, `resources/`.
2. **Utilities → Add-Ins** (Shift+S), вкладка Add-Ins, выберите DrawingSet → **Run**.
   Появится сообщение о загрузке; кнопки — во вкладке **UTILITIES**, панель **ADD-INS**.
3. Откройте модель изделия, нажмите **DrawingSet: Комплект чертежей** — откроется палитра.
   Проверьте вкладки настроек (папка вывода — на вкладке «Экспорт»), нажмите
   **Сгенерировать**: листы появятся в списке слева. Просмотрите, затем **Экспорт**.
4. **DrawingSet: Спецификация** — только анализ (CSV + отчёт со смещениями разнесения),
   удобно для подбора коэффициентов. **DrawingSet: Проверка API** — что умеет ваша версия
   Fusion (нужно только для запасного режима «через Fusion Drawing»).

Настройки: `~/DrawingSet/DrawingSet.settings.json`; логи: `~/DrawingSet/logs`; вывод по
умолчанию: `~/DrawingSet/out`.

## Структура модели, которую ожидает add-in

Все допущения настраиваются на вкладке «Модель».

| Вопрос | Принято |
|---|---|
| Панель — компонент или тело? | Вхождение компонента с твёрдыми телами. Компонент без дочерних вхождений = деталь; с дочерними = подсборка. Одинаковые панели (вхождения одного компонента или равные по названию/материалу/толщине/размеру) объединяются с суммой количества. |
| Формат имени | `{проект}_{вид}_{позиция}_{наименование}`, например `37-4_В1_П03_Боковина`; регулярное выражение с группами `project, view, pos, title`. Суффикс `:1` игнорируется. Имя не по шаблону → позиция ищется отдельным токеном, иначе пустая (предупреждение). |
| Материал | физический материал первого твёрдого тела, иначе материала компонента. |
| Толщина и размер | из ориентированного минимального бокса: толщина = наименьший габарит, Д×Ш = остальные два (мм, 0,1). |
| Кромка | атрибут компонента или тела (группа `DrawingSet`, имя `edge`) либо шаблон в имени с группой `(?P<edge>…)`. Попадает в шапку детали, «Примечание» спецификации и `description`. |
| Фурнитура | по ключевым словам в названии или по геометрии (мелкая неплоская деталь). На чертежах скрыта/показана по настройке, сведена в таблицу фурнитуры. |
| Разрезы / выносные виды | не строятся; маркеры (плоскости и эскизы с префиксом `РАЗРЕЗ`) перечисляются в отчёте и журнале как ручной шаг. |
| Листовой металл | тело с `isSheetMetal`; развёртка создаётся по наибольшей плоской грани, если её нет; гибы из `FlatPattern.getBendInfo` и активного правила (радиус, K-фактор, толщина). |

Скрытые (выключенная лампочка) вхождения пропускаются.

## Выход

* `…_СБ.pdf`, `…_ВЗР.pdf`, `…_ДЕТ.pdf` — по типу листов; `…_СВОД.pdf` — всё вместе.
* `…_СБ_л01.dxf`, `…_ДЕТ_л03.dxf` — листы в DXF (слои GEOM, HIDDEN, CENTER, DIM, TEXT, FRAME).
* `…_ДЕТ_03_Боковина_1к1.dxf` — контур детали 1:1 с отверстиями; читается вашим PWA-парсером
  (POLYLINE/CIRCLE) и любым CAM.
* `…_Спецификация.csv`, `…_Фурнитура.csv`, `…_Гибы.csv` — `;`, десятичная запятая, UTF-8 BOM.
* `…_ОТЧЁТ.txt` — таблицы, смещения разнесения, предупреждения, ручные шаги.

## Запасной режим: через Fusion Drawing

Флажок «Движок чертежей: через Fusion Drawing». Факты по справочнику API (майский релиз 2026):

* публичный `adsk.drawing` содержит только `Drawing`, `DrawingDocument`, `DrawingExportManager`,
  `PDFExportOptions` — листов, видов, размеров, выносок в API нет;
* в C++-заголовках есть скрытый `DrawingManager` с автосозданием чертежей и
  `AutomationPreferences` (в том числе `isAnimationSheetGenerated`), помеченный «hidden and not
  officially supported» и отсутствующий в Python-стабах; add-in проверяет его в рантайме;
* `AnimationManager`/`Storyboards.add` есть, команд Auto Explode и трансформации компонентов в
  раскадровке нет.

В этом режиме add-in использует скрытый API, если он виден из Python, иначе открывает диалог
«Создать чертёж» и подхватывает результат; взрыв-схема — по раскадровке `[EXPLODE]` или по
разнесённой копии дизайна; DXF/DWG листов — только командами UI.

## Проверка без Fusion

```bash
cd fusion/DrawingSet
python3 -m unittest discover -s tests -t .     # 52 теста: разбор имён, спецификация, разнесение, рендер, PDF/DXF
python3 tests/preview.py /tmp/drawingset       # комплект по синтетическому шкафу: PDF, SVG, DXF
```

## Структура

```
DrawingSet.py              точка входа: команды, палитра, события
lib/config.py              настройки (JSON), lib/ui.py — схема формы (нативный диалог и палитра)
lib/naming.py, bom.py      имена, спецификация, фурнитура, гибы, CSV
lib/model.py               обход модели Fusion; lib/extract.py — геометрия → Scene
lib/explode.py             геометрия разнесения (чистая); lib/explode_fusion.py — запасной режим
lib/scene.py, geom.py      данные геометрии, проекции
lib/render/                prims, views (художник), dims, balloons, tables, layout,
                           assembly, explode_sheet, details, sheetmetal, svg, pdf (+ttf), dxf
lib/docbuild.py            сборка комплекта и экспорт
lib/palette.py             мост с палитрой; resources/palette/ — HTML/CSS/JS
lib/pipeline.py            последовательность шагов, режимы render/export/spec/full
lib/drawing_driver.py, capabilities.py   запасной режим через Fusion Drawing
tests/                     unittest, synth.py и sample_cabinet.py — синтетическая модель
```
