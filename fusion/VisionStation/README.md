# Визуальная счётная станция — скрипт Fusion 360

Прототип станции счёта метизов по схеме «камера + ИИ»: оператор высыпает детали в загрузочный лоток
на старте ленты, планка-ограничитель выравнивает слой, лента 150×700 мм проносит детали под капотом
с камерой и подсветкой, счёт идёт на проходе, с конца ленты детали падают в воронку, заслонка на
сервоприводе отдаёт порцию в пакет или ковш на весах. На экране 7″ — живое видео и счёт.

Бункера и вибропитателя нет: загрузка вручную. Пневматики нет: заслонка на сервоприводе.
Детали с пометкой **[3D]** в модели печатаются на 3D-принтере (PETG).

## Запуск

1. Fusion 360 → **Utilities → Scripts and Add-Ins → Scripts → «+»** → выбрать папку `fusion/VisionStation`
   (или папку с `VisionStation_single.py` + `VisionStation_single.manifest`).
2. Новый документ Design → **Run**. В конце — окно с высотами, полем кадра камеры и временем детали в кадре,
   плюс список узлов, которые не построились, если такие есть.

Размеры — в `params.py` (все в мм), высоты считаются из них в `layout()`.
`EXPORT_DXF = True` выгружает эскизы плоских деталей (боковины, пластины, стенки капота) в `out/dxf`.

## Счёт камерой

- Камера с глобальным затвором на 300 мм над лентой, объектив 6 мм: поле ≈ 250×190 мм, лента 150 мм входит целиком.
- Скорость ленты 150 мм/с → деталь в кадре ≈ 1,7 с, при 20 кадрах/с — 30 кадров на деталь: трекинг надёжный.
- Первый вариант ПО — OpenCV на Pi 5: контрастная лента, контуры, трекинг через виртуальную линию счёта.
  Нейросеть (YOLO-nano на AI HAT+) — второй шаг, если детали ложатся внахлёст.
- Слой: планка-ограничитель с просветом 1,2 высоты детали сбрасывает лишнее назад; детали внахлёст — главный
  риск схемы, снимается скоростью ленты и тем, сколько оператор сыплет за раз.
- Когда счёт достиг задания: лента останавливается, заслонка отдаёт порцию, весы подтверждают массу.

## Что упрощено

- Скрипт написан по API Fusion и проверен на заглушке, в самом Fusion не прогонялся. Если узел не построится,
  окно отчёта назовёт его и ошибку — пришлите текст.
- Лента показана двумя плоскими ветвями без огибания роликов; ремень GT2 не нарисован.
- Заслонка показана закрытой, рычаг сервы условный.
- Покупные (камера, двигатель, серва, тензодатчик, дисплей) — габаритные тела типовых серий; после выбора
  моделей подставить размеры в `params.py`.
- Капот крупнее стола принтера: стенки из листа, печатаются только углы и кронштейны. Воронка 200×180×120 —
  две половины.

## Готовая модель без Fusion (CadQuery)

Та же сборка собирается здесь, в Python, по тем же `params.py` и `station.py`:

```bash
pip install cadquery
python3 fusion/VisionStation/cad_model.py   # out/VisionStation.step, .glb, .stl
python3 fusion/VisionStation/render.py      # out/view_iso.png, front, side, top
```

`cq_helpers.py` подменяет `helpers.py` на функции CadQuery, поэтому геометрия одна и та же.
`out/VisionStation.step` открывается в Fusion через Upload с деревом узлов и именами деталей;
`out/VisionStation.glb` смотрит `viewer.html` (интерактивный 3D-просмотр, опубликован как артефакт).
Имена с кириллицей после экспорта OCCT чинятся в `cad_model.py` (STEP — кодировка `\X2\`, glTF — UTF-8).
